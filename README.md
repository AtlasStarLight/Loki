# The Last NPC

A 2D pixel action game developed with Unity.

## Overview

The Last NPC is a 2D side-scrolling pixel action game.

The game focuses on boss battles, dodging mechanics, transformation skills, and level-based challenges.

## Engine

- Unity 2021.3
- 2D URP
- C#

## Genre

- 2D Action
- Pixel Game
- Side-scrolling Platformer
- Boss Battle

## Current Status

Core gameplay systems have been implemented.

Completed systems include:

- Player movement
- Jumping
- Dodging
- Attacking
- Transformation system
- Boss battle logic
- Skill system
- Level mechanics



## Main Features

- 2D pixel-style action gameplay
- Multiple boss fights
- Dodge-based combat system
- Transformation mechanics
- Skill cooldown system
- Level-specific rules and challenges

## Project Structure

- Assets
- Packages
- ProjectSettings

## How to Open

1. Clone this repository.
2. Open Unity Hub.
3. Click Add project from disk.
4. Select the project folder.
5. Open it with Unity 2021.3 or a compatible Unity version.
